# TaskFlow

TaskFlow is a simple task management application.

## Features

- User registration
- User login
- Password reset
- Create tasks
- Delete tasks
- Export tasks as CSV

## Authentication

Users authenticate using email and password.

## Password Reset

Users can request a password reset link through their registered email address.

Password reset links remain valid for 30 minutes.

## Task Management

Authenticated users can create and delete their own tasks.

Tasks support LOW, MEDIUM and HIGH priorities.
